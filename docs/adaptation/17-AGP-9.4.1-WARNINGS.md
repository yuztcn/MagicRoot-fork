# AGP 9.4.1 升级与构建警告清理

当前工具链：

```text
Android Gradle Plugin : 9.4.1（最新稳定）
Gradle                : 9.6.0（AGP 9.4.1 最低要求）
Kotlin / Compose      : 2.4.20 / 1.12.0
compileSdk / target   : 37
```

## 警告清理

1. `sourceSets ... assets.srcDirs/res.srcDirs` 在 AGP 9.4 已弃用：
   改为 `assets.directories.add(...)` / `res.directories.add(...)`。
2. Compose 依赖访问器 `compose.runtime/foundation/ui` 已弃用：
   改为显式依赖：
   ```kotlin
   org.jetbrains.compose.runtime:runtime:1.12.0
   org.jetbrains.compose.foundation:foundation:1.12.0
   org.jetbrains.compose.ui:ui:1.12.0
   ```
3. `LocalClipboardManager` 已弃用：
   改用 `LocalClipboard` + `ClipEntry(ClipData.newPlainText(...))` +
   `setClipEntry()`。
4. `stellar-provider.jar` 的类缺少 StackMapTable，R8 报
   “Expected stack map table”：
   - 用 ASM 将其中类文件降为 Java 5 版本并去掉旧帧；
   - 生成 `stellar-provider.jar` 替换原 stub；
   - R8 警告消失。
5. `libandroidx.graphics.path.so` 的 “Unable to strip”：
   ```kotlin
   packaging {
       jniLibs.keepDebugSymbols += setOf("**/libandroidx.graphics.path.so")
   }
   ```

## 验证

```text
gradle --warning-mode all :app:assembleRelease
BUILD SUCCESSFUL
无 WARNING / w: / deprecation 输出
```

最终 APK 使用 AGP 9.4.1/Gradle 9.6.0 构建；legacy 构建也通过。

## 注意

- Gradle 9.6.0 包需从 services.gradle.org 重定向到 GitHub 下载；本机构建使用了预先下载并解压的 Gradle 9.6.0。
- `stellar-provider.jar` 已做版本降级修复，建议在真机验证 Stellar 授权/进程路径。
